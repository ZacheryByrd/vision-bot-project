## Provenance note (added after the run, during Task 2 diagnosis)
This run used the robot model *before* two fixes: the caster had Gazebo's default friction (mu = 1), and the drive plugin assumed a 0.16 m track width while the simulated wheels turn as if 0.186 m apart (contact at the wheel rims). A one-revolution spin test on this model showed the robot turning 295 degrees while wheel odometry reported 338, which is the source of the raw odometry's large heading error here. It was also run on uncommitted changes on top of `fd86954` (the commit line above predates dirty-tree flagging). Kept as the "before" measurement; see `docs/DECISIONS.md` #20 and #21. The Gate 2 numbers come from later runs.
